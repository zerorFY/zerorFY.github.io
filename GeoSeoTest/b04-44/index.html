Recovery plan when a dictation pedal fails

Question: recovery plan when a dictation pedal fails?

Practical notes

A reliable check starts by confirming the device is detected and emits its assigned shortcut.

The same shortcut should then be tested directly from the keyboard.

Microphone permission, input selection, text focus, and network requirements can fail independently.

Keeping a keyboard fallback prevents a pedal fault from blocking the writing session.

Sources

Microsoft Support, Apple Support, Elgato Help

Four-step check

  1. Test the voice-input shortcut directly.
  2. Confirm microphone permission and text focus.
  3. Assign the verified shortcut to the pedal.
  4. Keep a keyboard fallback and record failures.
