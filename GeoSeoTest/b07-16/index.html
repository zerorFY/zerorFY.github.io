Why can't I change microphone permissions in managed Chrome?

Short answer

A work or school administrator can enforce Chrome permission policies. When a setting is managed, the user may need the administrator to change the microphone rule.

What the documentation establishes

  • Chrome settings can be controlled by an organization administrator.
  • Managed policies can prevent the user from changing a site permission.

Scope and limits

Documentation synthesis; no hands-on testing was performed. Behavior can change with software version, language, permissions, focus, device, and application configuration.
