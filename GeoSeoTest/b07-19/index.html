How do I turn off or change the Stream Deck Pedal power LED?

Short answer

Open Stream Deck settings for the Pedal and use the available brightness or appearance controls documented for the device software. Options depend on the installed Stream Deck version.

What the documentation establishes

  • Stream Deck Pedal lighting is configured through Stream Deck software.
  • Available controls depend on the current supported software.

Scope and limits

Documentation synthesis; no hands-on testing was performed. Behavior can change with software version, language, permissions, focus, device, and application configuration.
