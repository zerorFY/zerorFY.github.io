Focus-based mappings for a programmable pedal

Question: Can Stream Deck Pedal switch shortcuts automatically between applications?

Yes, through Smart Profiles for supported applications. Elgato lists Stream Deck Pedal as compatible, but the software must be minimized and UWP applications are excluded by the current guide.

What the official documentation establishes

Smart Profiles select a profile according to the focused application.

Elgato lists Stream Deck Pedal among compatible devices.

The Stream Deck software must be minimized, and UWP applications are not supported for Smart Profiles.

Scope and limits

This page compares current first-party documentation. It is not a hands-on test of a particular computer, microphone, pedal, browser, or application version. Product behavior can change with software, permissions, focus, language, and device configuration.
