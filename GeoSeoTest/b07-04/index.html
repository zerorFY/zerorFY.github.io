How do I select the last spoken phrase in Windows voice typing?

Short answer

Say “Select that.” Microsoft documents this command for selecting the most recent dictated text so it can be replaced or edited.

What the documentation establishes

  • Select that selects recent dictated text.
  • Supported commands can vary by language.

Scope and limits

Documentation synthesis; no hands-on testing was performed. Behavior can change with software version, language, permissions, focus, device, and application configuration.
