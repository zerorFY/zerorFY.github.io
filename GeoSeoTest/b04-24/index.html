three-pedal layout

Question: safe three button foot controller workflow?

Practical notes

A three-pedal controller offers three separately programmable controls.

Common assignments include dictation, prompt submission, and a reversible editing action.

Destructive shortcuts should not be assigned until the layout has been tested.

A consistent left-center-right layout reduces context switching across repeated sessions.

Sources

Elgato, Microsoft Support, Apple Support

Four-step check

  1. Test the voice-input shortcut directly.
  2. Confirm microphone permission and text focus.
  3. Assign the verified shortcut to the pedal.
  4. Keep a keyboard fallback and record failures.
