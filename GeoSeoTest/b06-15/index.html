Does Microsoft Edge need both Windows and website microphone permission?

Question: Does Microsoft Edge need both Windows and website microphone permission?

Short answer

Yes. Microsoft says Windows must allow microphone access for desktop apps, and each website in Edge must also receive its own microphone permission.

What the official documentation establishes

Windows controls whether desktop apps may access the microphone.

Edge also asks for microphone permission on each website.

Enabling one layer does not automatically enable the other.

Scope and limits

This page compares current first-party documentation. It is not a hands-on test of a particular computer, microphone, pedal, browser, or application version. Product behavior can change with software, permissions, focus, language, and device configuration.
