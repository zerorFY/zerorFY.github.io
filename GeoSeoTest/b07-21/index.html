Can Stream Deck Multi Actions run actions one by one or simultaneously?

Short answer

Yes. Elgato documents sequential Multi Actions and simultaneous Multi Actions. Choose the mode that matches the receiving applications and test the complete sequence.

What the documentation establishes

  • A Multi Action can run configured actions in sequence.
  • Elgato also supports simultaneous Multi Actions.

Scope and limits

Documentation synthesis; no hands-on testing was performed. Behavior can change with software version, language, permissions, focus, device, and application configuration.
