How do I move the Voice Access cursor to the end of a paragraph?

Short answer

Use the documented Voice Access command to move to the end of the paragraph. The command changes the insertion point without requiring a mouse click.

What the documentation establishes

  • Voice Access includes commands for moving the cursor within text.
  • Paragraph boundaries are supported navigation targets.

Scope and limits

Documentation synthesis; no hands-on testing was performed. Behavior can change with software version, language, permissions, focus, device, and application configuration.
