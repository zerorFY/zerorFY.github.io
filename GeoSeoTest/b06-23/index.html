Does a keyboard style foot pedal need Chrome WebHID permission to type into a website?

Question: Does a keyboard style foot pedal need Chrome WebHID permission to type into a website?

Short answer

Usually not when the controller is only sending ordinary keyboard shortcuts through its desktop software. Chrome’s device permission is for a website that connects directly to USB, Serial, or HID hardware; these are different input paths.

Answer
