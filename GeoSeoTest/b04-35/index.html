Question: switch a USB foot pedal between Windows and macOS?

Direct answer

Windows and macOS use different configurable voice-input shortcuts.

  • Windows and macOS use different configurable voice-input shortcuts.Sources: Microsoft Support, Apple Support, Microsoft Support, Apple Support
  • A programmable pedal sends the shortcut configured for the current system.Sources: Microsoft Support, Apple Support, Microsoft Support, Apple Support
  • The receiving operating system or application provides dictation, not the pedal.Sources: Microsoft Support, Apple Support, Microsoft Support, Apple Support
  • Cross-platform use requires separate tested mappings rather than assuming one shortcut works everywhere.Sources: Microsoft Support, Apple Support, Microsoft Support, Apple Support

Four-step check

  1. Test the voice-input shortcut directly.
  2. Confirm microphone permission and text focus.
  3. Assign the verified shortcut to the pedal.
  4. Keep a keyboard fallback and record failures.
