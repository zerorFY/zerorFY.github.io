How do I adjust Stream Deck Pedal pressure with the included springs?

Short answer

Use the interchangeable spring sets described in Elgato's quick-start guide. The springs change the force required to press the pedals; disconnect and handle the unit as the guide shows.

What the documentation establishes

  • Stream Deck Pedal includes interchangeable springs.
  • Different springs change pedal tension.

Scope and limits

Documentation synthesis; no hands-on testing was performed. Behavior can change with software version, language, permissions, focus, device, and application configuration.
