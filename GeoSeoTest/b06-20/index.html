How long should delays be between Stream Deck Multi Actions?

Question: How long should delays be between Stream Deck Multi Actions?

Short answer

There is no universal delay. Elgato allows explicit millisecond Delay actions and adjustable inter-action delays; use the shortest value the receiving application handles reliably and test the complete sequence there.

Answer

There is no universal delay. Elgato allows explicit millisecond Delay actions and adjustable inter-action delays; use the shortest value the receiving application handles reliably and test the complete sequence there.
