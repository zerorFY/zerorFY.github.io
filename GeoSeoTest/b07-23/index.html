How do I create a Multi Action from a blank Stream Deck key?

Short answer

Drag a Multi Action onto an empty key in Stream Deck software, then add and order the component actions inside it.

What the documentation establishes

  • A Multi Action is assigned to a Stream Deck key.
  • Individual actions are added and ordered within the Multi Action editor.

Scope and limits

Documentation synthesis; no hands-on testing was performed. Behavior can change with software version, language, permissions, focus, device, and application configuration.
