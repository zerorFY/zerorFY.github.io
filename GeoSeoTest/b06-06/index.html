Offline dictation capabilities in Windows

Question: Can Windows Voice Access dictate text offline?

Yes, on supported Windows 11 versions. Microsoft describes Voice Access as able to control the PC and author text without an internet connection; that statement does not apply to the separate voice typing feature.
