Windows speech input connection notes

Question: Does Windows voice typing work without an internet connection?

No. Microsoft says Windows voice typing uses online speech recognition and requires an internet connection; Windows Voice Access is the separate offline-capable option on supported Windows 11 versions.

What the official documentation establishes

Windows voice typing uses online speech recognition.

Voice typing requires an internet connection, a working microphone, and the cursor in a text box.

Windows Voice Access can dictate and control the PC without an internet connection on supported Windows 11 versions.

Scope and limits

This page compares current first-party documentation. It is not a hands-on test of a particular computer, microphone, pedal, browser, or application version. Product behavior can change with software, permissions, focus, language, and device configuration.
