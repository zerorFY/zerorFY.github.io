Punctuation and formatting while dictating on Mac

Question: Which spoken commands insert punctuation during Mac Dictation?

Mac Dictation accepts spoken names such as comma, question mark, open quote, new line, and new paragraph. Apple’s command list varies in practice by language and feature support.

What the official documentation establishes

Apple lists spoken commands for punctuation marks and symbols.

New line and new paragraph are documented formatting commands.

Automatic punctuation is available only for supported languages.

Scope and limits

This page compares current first-party documentation. It is not a hands-on test of a particular computer, microphone, pedal, browser, or application version. Product behavior can change with software, permissions, focus, language, and device configuration.
