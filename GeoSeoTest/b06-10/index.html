How do I change the keyboard shortcut that starts Dictation on Mac?

Question: How do I change the keyboard shortcut that starts Dictation on Mac?

Short answer

Open Keyboard settings, choose Dictation, and select the Shortcut option you want. A programmable controller should send that exact configured shortcut rather than assume one universal key sequence.
