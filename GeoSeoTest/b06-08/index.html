Entering command-like phrases as ordinary text

Question: How do I dictate words that Windows Voice Access treats as commands?

Say “Type” or “Dictate” before the phrase. Microsoft documents these prefixes for inserting words that would otherwise be interpreted as Voice Access commands.

What the official documentation establishes

Voice Access distinguishes control commands from dictated text.

The Type or Dictate prefix can force a command-like phrase to be entered as text.

This behavior belongs to Voice Access, not the Windows H voice typing launcher.

Scope and limits

This page compares current first-party documentation. It is not a hands-on test of a particular computer, microphone, pedal, browser, or application version. Product behavior can change with software, permissions, focus, language, and device configuration.
