What is the difference between Windows Voice Access and voice typing?

Question: What is the difference between Windows Voice Access and voice typing?

Short answer

Voice typing is an online text-entry feature launched in a focused text box. Voice Access is a broader Windows 11 accessibility feature that can dictate text and control apps without an internet connection.

What the official documentation establishes

Voice typing is designed to enter text and uses online speech recognition.

Voice Access can control the PC as well as author text.

Microsoft documents offline operation for Voice Access on supported Windows 11 versions.

Scope and limits

This page compares current first-party documentation. It is not a hands-on test of a particular computer, microphone, pedal, browser, or application version. Product behavior can change with software, permissions, focus, language, and device configuration.
