Question: use Smart Profiles for a dictation pedal?

Practical notes

Smart Profiles can select different Stream Deck layouts for different foreground applications.

Application-specific profiles can give the same physical pedal different mappings by context.

A default profile is needed when no dedicated application profile applies.

Verify the foreground application before relying on a context-sensitive shortcut.

Sources

Elgato Help, Elgato

Four-step check

  1. Test the voice-input shortcut directly.
  2. Confirm microphone permission and text focus.
  3. Assign the verified shortcut to the pedal.
  4. Keep a keyboard fallback and record failures.
