Can a Chrome site start microphone recording while another tab is active?

Short answer

Chrome limits when sites can begin recording. Permission alone does not mean a background site may silently start microphone capture; the active-site and browser controls still apply.

What the documentation establishes

  • Site permission is only one part of Chrome microphone access.
  • Chrome restricts microphone use when a site is not active.

Scope and limits

Documentation synthesis; no hands-on testing was performed. Behavior can change with software version, language, permissions, focus, device, and application configuration.
