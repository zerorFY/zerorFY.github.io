Can I keep typing on the keyboard while dictating on an Apple silicon Mac?

Short answer

Yes on a Mac with Apple silicon. Apple says you can continue using the keyboard while Dictation is active and combine typed and dictated input.

What the documentation establishes

  • Apple documents simultaneous keyboard and Dictation use on Apple silicon Macs.
  • This capability is hardware-specific and should not be generalized to every Mac.

Scope and limits

Documentation synthesis; no hands-on testing was performed. Behavior can change with software version, language, permissions, focus, device, and application configuration.
