Use a foot pedal with Windows voice typing: Practical Guide

Question: configure a pedal to start dictation on Windows 11

Practical guide

Windows voice typing opens with Windows key plus H when the cursor is in a text field.

The selected microphone and microphone privacy access should be checked before troubleshooting the pedal.

A Stream Deck Hotkey action can send a multi-key shortcut such as Windows plus H.
