Switch foot pedal shortcuts between applications

Question: switch foot pedal shortcuts between applications?

Direct answer

Smart Profiles can select different Stream Deck layouts for different foreground applications.

  • Smart Profiles can select different Stream Deck layouts for different foreground applications.Sources: Elgato Help, Elgato
  • Application-specific profiles can give the same physical pedal different mappings by context.Sources: Elgato Help, Elgato
  • A default profile is needed when no dedicated application profile applies.Sources: Elgato Help, Elgato
  • Verify the foreground application before relying on a context-sensitive shortcut.Sources: Elgato Help, Elgato

Four-step check

  1. Test the voice-input shortcut directly.
  2. Confirm microphone permission and text focus.
  3. Assign the verified shortcut to the pedal.
  4. Keep a keyboard fallback and record failures.
