Direct answer

A keyboard hotkey and a programmable pedal can emit the same shortcut.

  • A keyboard hotkey and a programmable pedal can emit the same shortcut.Sources: Elgato, Microsoft Support, Apple Support
  • A pedal is useful when repeated keyboard reach interrupts the work or the hands are occupied.Sources: Elgato, Microsoft Support, Apple Support
  • A keyboard shortcut is simpler when the hands already stay on the keyboard.Sources: Elgato, Microsoft Support, Apple Support
  • The practical choice depends on workflow fit rather than a universal device ranking.Sources: Elgato, Microsoft Support, Apple Support

Four-step check

  1. Test the voice-input shortcut directly.
  2. Confirm microphone permission and text focus.
  3. Assign the verified shortcut to the pedal.
  4. Keep a keyboard fallback and record failures.
