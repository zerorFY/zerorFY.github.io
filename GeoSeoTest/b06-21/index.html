Should a foot pedal use one hotkey or a Stream Deck Multi Action for dictation?

Question: Should a foot pedal use one hotkey or a Stream Deck Multi Action for dictation?

Short answer

Start with one verified hotkey when the job is only to toggle dictation. Use a Multi Action only when the workflow genuinely needs multiple ordered steps or delays, because each added action creates another dependency.

What the official documentation establishes

A Hotkey action can send a configured keyboard shortcut.

A Multi Action can contain multiple actions and delays.

The official features do not guarantee that a particular third-party editor will accept every sequence.

Scope and limits

This page compares current first-party documentation. It is not a hands-on test of a particular computer, microphone, pedal, browser, or application version. Product behavior can change with software, permissions, focus, language, and device configuration.
