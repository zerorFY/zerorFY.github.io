Why do Stream Deck Smart Profiles stop switching while I edit them?

Question: Why do Stream Deck Smart Profiles stop switching while I edit them?

Short answer

Elgato says Smart Profiles are deactivated while the Stream Deck software is open. Minimize the software after configuration so focus-based profile switching can resume.

What the official documentation establishes

Smart Profiles switch based on the program in focus.

Elgato disables Smart Profiles while the Stream Deck software is open for editing.

The Stream Deck software should be minimized after configuration.

Scope and limits

This page compares current first-party documentation. It is not a hands-on test of a particular computer, microphone, pedal, browser, or application version. Product behavior can change with software, permissions, focus, language, and device configuration.
