Map a programmable pedal to Mac dictation

This guide explains how to map a programmable pedal to Mac dictation.

Direct answer

macOS Dictation can be started with the configured Dictation keyboard shortcut.

  • macOS Dictation can be started with the configured Dictation keyboard shortcut. Sources: Apple Support, Apple Support
  • A programmable pedal can emit the same shortcut assigned to Dictation. Sources: Elgato, Apple Support
  • Dictation availability and behavior depend on macOS settings and language support. Sources: Apple Support
  • The active application must accept text input for dictated text to appear there. Sources: Apple Support

Workflow boundary

Test the assigned shortcut in the target application before relying on it. Keep a keyboard fallback available.
