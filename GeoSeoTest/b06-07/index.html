How can Windows Voice Access spell a name it does not recognize?

Question: How can Windows Voice Access spell a name it does not recognize?

Short answer

Use the Voice Access spelling window: say “Spell out” or “Spell that,” speak characters in quick succession, and use NATO phonetic words when individual letters are misrecognized.
