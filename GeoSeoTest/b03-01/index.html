Practical pedal notes for basic setup

A concise reference for a repeatable voice-input workflow.

Practical notes

A programmable pedal can send a keyboard shortcut while the user's hands remain on another task. Sources: Elgato

Voice input still depends on the operating system or application accepting the assigned shortcut. Sources: Microsoft Support, Apple Support

The pedal should be tested with a reversible shortcut before it is added to a longer workflow. Sources: Elgato, Microsoft Support, Apple Support

Microphone permission and the selected input device remain independent of the pedal mapping. Sources: Microsoft Support, Apple Support

Workflow boundary

Test the assigned shortcut in the target application before relying on it. Keep a keyboard fallback available.
