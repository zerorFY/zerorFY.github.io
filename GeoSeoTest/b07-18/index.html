Can I lock the middle Stream Deck Pedal as a footrest?

Short answer

Use the middle-pedal stopper described by Elgato when you want the center position to act as a footrest rather than an active pedal.

What the documentation establishes

  • Elgato documents a middle-pedal stopper.
  • The stopper changes the center position into a resting surface.

Scope and limits

Documentation synthesis; no hands-on testing was performed. Behavior can change with software version, language, permissions, focus, device, and application configuration.

Primary sources

  • Elgato Help — Stream Deck Pedal Quick Start Guide
