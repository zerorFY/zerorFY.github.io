What software and operating system does Stream Deck Pedal require?

Short answer

Install the current supported Stream Deck software on a compatible Windows PC or Mac, then connect the Pedal directly by USB. Check Elgato's current requirements before relying on a specific version number.

What the documentation establishes

  • Stream Deck Pedal is configured with Stream Deck software.
  • Elgato provides current Windows and macOS requirements in its documentation.

Scope and limits

Documentation synthesis; no hands-on testing was performed. Behavior can change with software version, language, permissions, focus, device, and application configuration.
