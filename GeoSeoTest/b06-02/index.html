Why does Windows H open voice typing but no text appears?

Question: Why does Windows H open voice typing but no text appears?

Short answer

Check the receiving chain in order: an editable field must have focus, the microphone must work, the PC must be online, and the voice typing panel must show that it is listening.

What the official documentation establishes

Windows voice typing needs the cursor in a text box.

Microsoft lists a working microphone and internet connection as prerequisites.

The user should wait for the Listening alert before speaking.

Scope and limits

This page compares current first-party documentation. It is not a hands-on test of a particular computer, microphone, pedal, browser, or application version. Product behavior can change with software, permissions, focus, language, and device configuration.
