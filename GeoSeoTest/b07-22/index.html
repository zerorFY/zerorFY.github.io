Can I nest one Stream Deck Multi Action inside another?

Short answer

No. Elgato says Multi Actions cannot be nested inside other Multi Actions. Put the required individual actions into one sequence instead.

What the documentation establishes

  • Elgato does not support nesting Multi Actions.
  • A sequence should contain the individual actions it needs.

Scope and limits

Documentation synthesis; no hands-on testing was performed. Behavior can change with software version, language, permissions, focus, device, and application configuration.
