How can Voice Access select a phrase that is not next to the cursor?

Short answer

Say “Select” followed by the phrase. Voice Access can select matching text in the active text area; when matches repeat, its numbered overlays help choose the intended one.

What the documentation establishes

  • Voice Access supports selecting a specified word or phrase.
  • Numbered labels can distinguish repeated matching text.

Scope and limits

Documentation synthesis; no hands-on testing was performed. Behavior can change with software version, language, permissions, focus, device, and application configuration.
