Temporary and continuing Chrome microphone access

Question: What is the difference between Allow this time and Allow while visiting in Chrome microphone permissions?

Allow this time applies only to the current visit. Allow while visiting permits use during the current and future visits, while Chrome still limits recording behavior when the site is not the active tab or app.

What the official documentation establishes

Chrome offers one-time and continuing per-site permission choices.

Allow this time must be requested again on a later visit.

Allow while visiting persists for future visits unless the permission is changed or removed.

Scope and limits

This page compares current first-party documentation. It is not a hands-on test of a particular computer, microphone, pedal, browser, or application version. Product behavior can change with software, permissions, focus, language, and device configuration.
