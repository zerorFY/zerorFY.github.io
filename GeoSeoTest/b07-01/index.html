How do I pause Windows voice typing without closing the launcher?

Short answer

Say “Pause voice typing.” Microsoft lists it as a voice typing command, allowing the launcher to remain available while dictation pauses.

What the documentation establishes

  • Microsoft lists Pause voice typing as a supported command.
  • Voice commands depend on the active voice typing language.

Scope and limits

Documentation synthesis; no hands-on testing was performed. Behavior can change with software version, language, permissions, focus, device, and application configuration.

Primary sources

  • Microsoft Support — Use voice typing to talk instead of type on your PC
