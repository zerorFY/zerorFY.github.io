How do I remove a saved microphone permission from a site in Chrome?

Short answer

Open Chrome site settings for the microphone, find the site, and remove or reset its saved permission. Chrome will ask again the next time the site requests access.

What the documentation establishes

  • Chrome stores microphone choices per site.
  • A saved site permission can be changed or removed in Site settings.

Scope and limits

Documentation synthesis; no hands-on testing was performed. Behavior can change with software version, language, permissions, focus, device, and application configuration.
