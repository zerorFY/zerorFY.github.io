microphone troubleshooting

Question: troubleshoot microphone permission for pedal dictation?

Practical notes

Pedal input and microphone input are separate parts of the workflow.

A working pedal cannot fix a muted, unavailable, or unpermitted microphone.

Testing voice input without the pedal isolates microphone and permission problems.

Testing the assigned shortcut on the keyboard isolates pedal-mapping problems.

Sources

Microsoft Support, Apple Support, Elgato Help

Four-step check

  1. Test the voice-input shortcut directly.
  2. Confirm microphone permission and text focus.
  3. Assign the verified shortcut to the pedal.
  4. Keep a keyboard fallback and record failures.
